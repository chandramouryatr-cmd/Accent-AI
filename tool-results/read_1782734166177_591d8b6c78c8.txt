     1→# AccentAI — Project Worklog
     2→
     3→## Project Overview
     4→AccentAI is a comprehensive English accent learning app. 8 phases × 4 lessons = 32 lessons. Every lesson must be fully functional with interactive micro-animations and vector animations.
     5→
     6→## Tech Stack
     7→- Next.js 16 (App Router), TypeScript 5
     8→- Tailwind CSS 4 + shadcn/ui (New York)
     9→- Zustand (client state) + persist middleware
    10→- Framer Motion (micro-animations)
    11→- Web Audio API + Web Speech API (TTS/pronunciation)
    12→- Dark/light theme (dark default; indigo/violet/cyan palette from uploaded design)
    13→
    14→## Architecture
    15→- Single `/` route (SPA). View switching via Zustand `activeTab`.
    16→- `src/lib/types.ts` — Lesson schema (16 step types)
    17→- `src/lib/store.ts` — Zustand store with progress persistence
    18→- `src/lib/lessons/` — 8 phase folders, each with 4 lesson files (l1-l4.ts)
    19→- `src/lib/lessons/index.ts` — registry importing all 32 lessons
    20→- `src/components/widgets/` — reusable animated SVG/Canvas widgets
    21→- `src/components/lesson/` — LessonModal + step renderers
    22→- `src/components/views/` — Dashboard, Journey, Practice, Progress, More
    23→
    24→## Lesson Step Types (16)
    25→1. `intro` — hero with animated visual
    26→2. `concept` — heading + body + bullets + animated visual
    27→3. `example` — phrase + IPA + TTS play + tap-words
    28→4. `mouth-diagram` — SVG mouth cross-section, animated tongue/lips
    29→5. `vowel-chart` — IPA vowel quadrilateral, tap dots
    30→6. `compare` — native vs learner waveforms
    31→7. `stress-bars` — syllable stress visualization
    32→8. `rhythm` — animated rhythm beats
    33→9. `linking` — connected speech linking visualization
    34→10. `shadow` — shadow speaking practice
    35→11. `intonation` — pitch contour SVG
    36→12. `tap-pronounce` — tap words to hear
    37→13. `tip` — highlighted tip card
    38→14. `practice` — record + score
    39→15. `quiz` — multiple choice with explanation
    40→16. `completion` — XP, badge, confetti
